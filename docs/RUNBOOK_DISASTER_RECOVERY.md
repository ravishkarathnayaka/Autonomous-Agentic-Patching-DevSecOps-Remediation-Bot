## 1. Emergency Agent Kill-Switch

If the bot generates anomalous pull requests or unexpected behavior occurs in production/staging repositories:

### Immediate Remediation Freeze
1. Terminate running CLI processes:
   ```bash
   pkill -f "remediate" || taskkill /F /IM python.exe
   ```
2. Disable GitHub Actions automated remediation workflows:
   ```bash
   gh workflow disable "Autonomous Remediation Pipeline"
   ```
3. Lock bot service account branch write permissions in GitHub Settings -> Branches -> Branch Protection Rules.

## 4. Ephemeral Sandbox Breach Containment

All test verification executes within unprivileged Docker containers bounded by:
- Memory limits: `512MB`
- CPU quotas: `50,000` (50% single core)
- PID limits: `50` processes maximum
- Read-only root filesystem with isolated temporary `/tmp` volume
- Custom Seccomp profile blocking dangerous system calls (`ptrace`, `sys_chroot`, `reboot`, `bpf`)

If sandbox anomalies occur, purge container images and restart the Docker daemon:
```bash
docker rm -f $(docker ps -aq --filter "label=devsecops.sandbox=true")
docker system prune -f
```

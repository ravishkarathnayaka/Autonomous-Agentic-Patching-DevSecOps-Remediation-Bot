# Enterprise Deployment & DevSecOps Governance Guide

This document provides architectural guidance, governance policies, and deployment blueprints for integrating the **Autonomous Agentic Patching & DevSecOps Remediation Bot** into high-assurance enterprise software development lifecycles (SDLC).

## 2. Policy-Driven Remediation (`rules/default-remediation-policy.yml`)

Enterprises can customize remediation rules without altering bot source code:

- **Severity Thresholds**: Target only vulnerabilities matching or exceeding enterprise SLOs (e.g. `HIGH` or `CRITICAL` with CVSS >= 7.0).
- **Rule & CWE Inclusions**: Specifically prioritize high-exploit categories such as SQL Injection (CWE-89), Command Injection (CWE-78), Path Traversal (CWE-22), and Insecure Deserialization (CWE-502).
- **Path Exclusions**: Protect legacy or test code by excluding directories like `tests/fixtures/**`, `docs/**`, or vendored third-party dependencies.

## 3. Ephemeral Sandbox Security Safeguards

To prevent untrusted code generated by AI models or third-party patches from executing in production runners:

1. **Zero Network Egress**: Containers run with `--network=none` to prevent data exfiltration and reverse shells.
2. **Restricted Seccomp Profile**: Blocks dangerous Linux kernel syscalls (`bpf`, `ptrace`, `kexec_load`, `mount`, etc.) via `docker/seccomp-profile.json`.
3. **Dropped Privileges**: Containers run as an unprivileged user (`sandboxuser:1000`) with `--cap-drop=ALL`.
4. **Strict Resource Quotas**: Hard memory limit of 512 MB and 1.0 CPU quota prevent denial-of-service / infinite loop bugs.

## 5. Webhook Notifications & Audit Trails

Remediation events can be broadcast to SOC and engineering channels via webhook dispatchers (`agent_engine/tools/notification_dispatcher.py`):

```bash
python cli/main.py run \
  --findings-file findings.json \
  --workspace . \
  --webhook-url https://hooks.slack.com/services/T00/B00/XXXXX
```

Every execution generates a comprehensive audit trail detailing:
- Scanned finding ID and CVSS score
- AST diff generated and applied
- Sandbox execution duration and test logs
- Created pull request branch and commit hash
